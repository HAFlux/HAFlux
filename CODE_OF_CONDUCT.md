# Code of Conduct

Проект следует [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Краткая версия:

- Уважительное общение. Без личных нападок, оскорблений, троллинга.
- Принимаем разнообразный технический и культурный опыт.
- Конструктивная обратная связь — на код, а не на человека.

Случаи нарушений направлять на `conduct@hapilot.dev` (контакт активируется ближе к публичному релизу). Жалобы рассматриваются конфиденциально.

# Security Policy

## Поддерживаемые версии

В стадии до v1.0 безопасность поддерживается только для последнего релиза. После v1.0 — `latest` и предыдущая major/LTS.

## Сообщить об уязвимости

**Не открывайте публичный issue** для уязвимостей.

- GitHub Security Advisory: вкладка `Security → Report a vulnerability` репозитория.
- E‑mail: `security@haflux.dev` (PGP‑ключ — в репозитории, файл `.well-known/pgp.asc`, появится ближе к публичному релизу).

В сообщении укажите:

1. Затронутые версии и компонент (api / web / agent).
2. Описание уязвимости и потенциальный impact.
3. Шаги воспроизведения или PoC.
4. Ваши контакты (опционально — для credit в advisory).

## SLA

- Подтверждение получения — в течение 72 часов.
- План фикса — в течение 14 дней.
- Релиз с патчем — как можно скорее, обычно ≤ 30 дней (зависит от сложности).

## Безопасные практики

- Секреты в БД (ACME‑токены, agent‑tokens, OIDC client secrets) шифруются `ENCRYPTION_KEY` (AES‑256‑GCM, envelope encryption).
- Канал agent ↔ api защищён mTLS.
- Образы в релизе подписываются Cosign, прикладывается SBOM (CycloneDX).
- Поддержка OWASP ASVS L2 как минимальная планка.
